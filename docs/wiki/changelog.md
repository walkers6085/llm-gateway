# История изменений

Новые записи — сверху. Правка модуля = строка здесь + правка его страницы вики.

## 2026-10-20 — повторы временных ошибок и очистка контекста

- 429 и временные HTTP/сетевые ошибки до начала ответа повторяются с backoff, jitter
  и Retry-After; ожидание отменяемо, сессия и инструменты не перезапускаются.
- В TUI показано ожидание повтора; model.retry сохраняет общую корреляцию и отдельные spans.
- Перед моделью очищается копия tool-результатов: ANSI/управляющие коды, whitespace JSON,
  лишние пустые строки. Код, числа, Unicode, вызовы и исходная история сохраняются.
  MCP не теряет уникальный structuredContent и не дублирует уже представленный JSON.
  [Обработка запросов](request-processing.md), [настройки](settings.md), [цикл](agent-loop.md),
  [LLM](llm-client.md), [MCP](mcp.md), [TUI](tui.md).

## 2026-10-20 — импорт/экспорт OpenCode и параметры моделей

- Добавлен явный обмен поддерживаемым JSON/JSONC: имена, API-ID, лимиты, параметры,
  default, enabled и free. Проверка перед записью, объединение по запросу, экспорт без секретов.
- F3 содержит импорт/экспорт и мастер моделей; отображаемые имена отделены от ID.
  Профили реально применяются в запросах и изолированы между провайдерами.
- mTLS/Basic и неподдерживаемые поля не теряются молча: обмен останавливается с объяснением.
  [OpenCode](opencode.md), [провайдеры](providers.md), [CLI](cli.md), [TUI](tui.md),
  [настройки](settings.md), [LLM](llm-client.md), [цикл](agent-loop.md).

- SQLite 6: надёжная FIFO-очередь, восстановление после отмены/закрытия, проверка хуками,
  отдельные снимки для файлового отката уточнений ([сессии](sessions.md)).

## 2026-10-20 — сводка и режимы доступа

- Ручной и автоматический compact: сводка текущей моделью без инструментов, обработка длинной истории частями, расход в бюджете/трассировке, локальный резерв при ошибке или отсутствии бюджета, отмена без изменения контрольной точки.
- Схема сессий 7: сохранённый режим доступа, атомарное применение сводки с проверкой истории.
- Общий стандарт CLI/сервера allow_all; явные настройки сохраняются. Строгий read_only нельзя обойти allow/always/хуком, shell и MCP запрещены. /permissions и меню TUI с сохранением общих настроек, режим в заголовке.

## 2026-10-20 — размеры окон по моделям

- /models сохраняет метаданные и aliases, подключение и серверный агент обнаруживают лимиты без обязательности каталога. Явное окно профиля, API и паспортный каталог заменяют общий размер; неизвестные модели явно помечены.
- Полное окно, лимит входа и резерв ответа показаны отдельно, в выборе моделей видны их размеры. Профили разных подключений не смешиваются. max_input_tokens/max_turn_tokens=0 включают автоопределение, явные ограничения сохраняются.
- Байт JSON больше не считается токеном: единая приблизительная оценка для цикла и сводки. OpenCode сохраняет context_window; неподдерживаемые сочетания ограничений явно отклоняются при экспорте.
