# Цель и задачи сессии

Код: [`agent/tools/planning.py`](../../../agent/tools/planning.py).
Инструменты `goal` и `todo` включены в стандартный `tools.enabled`. Если список инструментов
задан явно, добавьте эти имена в него. Дополнительных зависимостей и миграций БД нет.

- `goal({})` читает цель. `goal({"text":"Исправить ввод Unicode"})` меняет её;
  пустая строка очищает цель. Ограничение — 4000 символов.
- `todo({})` читает план. `todo({"items":[{"id":"test","text":"Проверить SSH","status":"in_progress"}]})`
  заменяет список целиком; `items: []` очищает список. Сохраняйте завершённые пункты.
  Статусы: `pending`, `in_progress`, `completed`, `cancelled`.
  Максимум 20 пунктов, уникальный непустой id до 40 символов, текст до 500 символов.

По умолчанию оба инструмента имеют `allow`: меняют только данные сессии, не файлы.
Правила deny/ask и хуки применяются как обычно. До явного изменения цель берётся из первого
запроса пользователя. Результат успешного инструмента сохраняется в метаданных сообщения
`planning` после проверки PostToolUse. Отказ, ошибка или блокирующий хук не меняют состояние.
Секреты маскируются стандартным механизмом сохранения сообщений.

`SessionStore.planning_state()` восстанавливает состояние по метаданным текущей ветки истории.
Поэтому `/compact` сохраняет цель и задачи, повторное открытие сессии восстанавливает их,
а `/revert` откатывает вместе с сообщениями. Архив ветки остаётся в экспорте.
Дочерняя сессия сабагента имеет собственный план, не перезаписывающий родительский.

Текущая цель и задачи подмешиваются во вход модели отдельным пользовательским сообщением
с пометкой «рабочие данные», даже после сжатия. Для входа цель ограничена 2000 символами,
текст пункта — 200; при небольшом лимите входа выдержки дополнительно уменьшаются.
Текущая цель заменяет отдельную вставку исходной цели, чтобы не дублировать её.
Полная версия хранится в метаданных. Правая панель TUI показывает
данные и обновляется после результата инструмента. Длинные блоки раскрываются
щелчком по заголовку, чтобы MCP и контекст оставались доступны без долгой прокрутки.

Goal и Todo отмечены plan_safe=True и работают у обоих активных агентов build/plan.
Переключение по Tab сохраняет цель и список задач; вопросы уточняются инструментом
[question](question.md). Изменение выбранного агента не пересоздаёт историю.
