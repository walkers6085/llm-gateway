# Версия 1.0.0: поставка и готовность к запуску

Дата подготовки: 2026-10-21. Поддерживаемая среда: Linux, Python 3.12/3.13.
Версия едина для пакета, CLI и метаданных API; источник — agent.__version__.
Пакет llm-gateway-agent включает агент, шлюз, бенчмарки, веб-чат и исходники OpenTUI.

## Что вошло

- Именованные провайдеры с отдельными секретами, Bearer/Basic/mTLS, импортом/экспортом OpenCode.
- OpenTUI: меню, модели всех провайдеров, сессии с названиями, редактирование/откат,
  история ввода, reasoning, контекст, уточнения во время работы и уведомления.
- Plan/Build, вопросы пользователю, переход к реализации и внутренние роли исследования/ревью.
- Сводка контекста через модель, индивидуальные окна, ограниченные ретраи, восстановление
  после обрыва потока без повторного исполнения завершённых шагов инструментов.
- Локальные сессии SQLite, журналирование по request_id/span_id, статистика и бенчмарки.
- Установленные команды gwagent, gwproviders, gwbench и gwtoken; ключ --version у каждой.

## Установка wheel

```bash
python3 -m venv venv
venv/bin/python -m pip install -c requirements.lock ./llm_gateway_agent-1.0.0-py3-none-any.whl
venv/bin/gwagent --version
venv/bin/gwagent
```

Файл requirements.lock поставляется рядом с wheel для проверенных версий зависимостей.
В CLI настройте подключение через /providers. Для OpenTUI нужен Bun:

```bash
venv/bin/gwagent tui install
venv/bin/gwagent --tui
```

Исходники TUI и чат входят в wheel. Установка UI отдельная: пакеты Bun автоматически
при обычном запуске не скачиваются. CI проверяет Bun 1.3.8 и 1.3.14; launcher версию
не запрещает. Для простого терминала есть --plain. Другие ОС и терминалы требуют
своей проверки; системные уведомления и звук зависят от возможностей клиента.

## Обновление и возврат

Завершите работающие CLI и сервер перед копированием SQLite. Сохраните резервную копию
каталога GWAGENT_HOME (по умолчанию ~/.gwagent), конфигурации шлюза и рабочей папки.
Секреты и сертификаты хранятся отдельно от пакета и в архив релиза не включаются.
Установите wheel в прежнее окружение либо новое venv и выполните gwagent --version,
затем gwagent doctor. В 1.0.0 новых миграций относительно коммита 44e8421 нет.
При возврате к более старому коду сверяйте поддерживаемую версию SQLite или восстанавливайте
его резервную копию. Переключение пакета не отменяет изменений в рабочей папке.

## Решение о запуске

CLI/OpenTUI можно выпускать для Linux и доверенной команды после прохождения локальных
проверок. mTLS-шлюз на текущей машине пока не готов к включению: нужны реальные
сертификаты/ключ, проверка URL/CA и интеграционный запрос к целевому апстриму.
Сервис при подготовке релиза не включается.

Перед серверным запуском задайте UPSTREAM_BASE_URL, CLIENT_CERT, CLIENT_KEY и CA_BUNDLE
при необходимости. Для установленного пакета задайте абсолютный DB_PATH и AGENT_CONFIG
через окружение сервиса; .env из произвольной текущей папки не подхватывается.
Выдавайте серверные токены с минимальным профилем, проверьте /live, /health, /models,
обычный и потоковый ответ, отмену и восстановление соединения на реальной инфраструктуре.
Затем владелец может включить серверный сервис и проверить перезапуск.

Перед публикацией версии на GitHub нужны зелёный CI релизного коммита, тег v1.0.0,
wheel, requirements.lock и SHA256SUMS. Сборка не публикует пакет в PyPI и не запускает сервис.

## Оставшиеся ограничения

Точный токенизатор и OS-песочница не добавлены. По умолчанию max_turn_tokens=0 отключает
общий бюджет, max_output_tokens=0 не ограничивает длину ответа; для сервера задавайте
подходящие лимиты и права профиля. Секреты в auth.json защищены правами, не шифрованием.
Квоты рассчитаны на один процесс сервера; распределённая установка требует доработки.
